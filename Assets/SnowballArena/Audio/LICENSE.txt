Background music (OpenGameArt, CC0 1.0)
--------------------------------------
  Music/menu_theme.ogg   <- "Swinging Sweet", from "Short Loops Background Music Pack" by hernandack
  Music/match_theme.ogg  <- "A Brand New Wisdom", same pack by hernandack
  https://opengameart.org/content/short-loops-background-music-pack

  The first match track tried was "rememberWinter" (Short Loop: winter theme by yd),
  but it measures ~25 dB RMS while the menu track sits at ~13 dB, so it was replaced
  with a track from the same loudness family (-14 dB) to keep the menu/match switch
  seamless. This track is 16.6 s so it loops more often than the 24.9 s menu track.

Cannon cues (Kenney, CC0 1.0)
-----------------------------
  Cannon/cannon_deploy.ogg      <- impactMetal_heavy_000.ogg    (Kenney Impact Sounds)

Generated by this project, not Kenney
-------------------------------------
  Cannon/cannon_flight.wav      <- whoosh: white noise through a falling one-pole low-pass, 0.42 s
  Cannon/cannon_warning.wav     <- 880 Hz tone with a second partial, exponential decay, 0.20 s
  Cannon/cannon_fire.wav        <- cannon shot, 0.65 s: 48->34 Hz sub thump + 88 Hz body +
                                   an 18 ms muzzle crack + a hard low-passed boom, no bright
                                   noise tail (a long bright tail is what read as a firework)
  Cannon/cannon_explosion.wav   <- solid ball impact, 0.50 s: 125/205 Hz knock + 62 Hz shock +
                                   short snow crunch + dust tail; measure L<150 Hz 80% of energy
  Reward/knockdown.wav          <- two bell notes, A5 then E6, additive sine partials, 0.55 s
